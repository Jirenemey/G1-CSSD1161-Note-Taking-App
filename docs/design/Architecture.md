# Architecture & Components

## Context 
- This section covers the architecture and components of the app. How the work flow of the app works and what part each component plays in it.

## Conent
- Main page of the app
    - One page that has indivdual sections that refresh with use.

- Create/Edit Component
    - This section let's you create and edit notes, add tags, content, and a title.

- List of Notes and Folders
    - This component let's you view your notes and folders.

- Filters
    - Let's you filter out notes and folders based on tags and titles.
